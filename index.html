一、出發前準備（核對與前置作業）[cite: 6]

1. 前置作業排程[cite: 6]

  • 出團前 7 天確認前置：主動聯繫團控，確認電話交團時間（統一出發前 3 個工作天）、確認團包內容與寄送資訊、報到點是否需要安排寄鋪。
  • 出團前 3 天發布行前提醒：出發 3 天前於群組發布完整注意事項清單，發布內容包含：自我介紹、集合時間與地點、遊覽車車號、每日天氣提醒、建議個人攜帶物品、行程飯店特別說明（如泳池開放與泳具攜帶）。[cite: 6]

2. 客群提問與上下車點嚴謹規範[cite: 6]

  • 群組問題回覆：旅客在群組發問旅遊相關問題，記得主動協助回覆；若該問題當下無法立即解決，請回覆客人：「確認後第一時間回覆給您。」[cite: 6]
  • 報名、座位與上車點異動：客人若提出報名、選座位、改上車點需求，請引導客人直接聯繫業務窗口，讓業務修改系統以確保資訊同步。[cite: 6]
  • 上下車點嚴禁私下答應：不論在群組或出團期間，客人要求修改、增加上下車點，切勿自行答應，請統一聯繫業務窗口。上車點皆為固定站點，不能因為順路就修改，此舉對其他準時依約前往的客人不公平，且一旦破例後續難以管理。[cite: 6]

3. 交團資料齊全度核對[cite: 6]

  • 線上領隊作業回報系統連結：[cite: 6]
    • 確認領隊日報檢查表是否與行前資料相符。[cite: 6]
    • 確認預支團支金額是否與實領款項相符。[cite: 6]
    • 確認分房表是否與座位報表席次相符。[cite: 6]
    • 註：線上系統內座位報表之完整個資解密密碼為當團出發日期（例如：20261005）。[cite: 6]
  • NAS 資料夾連結：[cite: 6]
    • 逐一核對派車報到單、車籍資料、客戶行前資料、操作書、分房表、飯店房號表、保險保單、車條、相關供應商預訂憑證與電子車票。[cite: 6]
    • 車況規格確認：務必確認操作書上遊覽車指定車齡在 5 年內，並核對車籍資料座位數（車籍座位數已包含司機大哥與領隊）。[cite: 6]
    • 保險保單查核：確認出團日期與人數相符，若有加保旅平險亦同步檢查。[cite: 6]
    • 行前資料核實：確認集合地點正確性（特殊集合點先以 Google 地圖確認街景與動線），並確認站與站之間的行車距離與預估時間。[cite: 6]

4. 團包物資清點[cite: 6]

  • 必備物件：團包袋子、領隊旗桿、何時制服與工裝背心、醫藥包、紅茶與綠茶茶包、專用茶壺、純水濕紙巾 1 包。[cite: 6]
  • 專案物資：合照布條、客人名牌、實體手冊、各團輔銷物（依各團型配置提供）。[cite: 6]

5. 供應商團確與行前聯繫[cite: 6]

  • 供應商團確：依操作書逐一聯繫車行、餐廳、景點、活動、飯店與寄鋪，出團前全數確認完畢，掌握現場接應細節。[cite: 6]
  • 司機大哥行前聯繫：出發前一天確實電話聯繫司機大哥，提醒集合時間、地點，並請車上備妥足量礦泉水、茶壺與熱水桶。若司機未接電話，切勿只傳簡訊，請回報團控由車行通知。[cite: 6]
  • 特殊團型與功課準備：初次帶領的路線，出團前請務必與線控主管卡卡聯繫；若為特別包團，與卡卡討論後務必再聯繫當團業務，了解客戶背景與窗口特性。[cite: 6]

6. 「款待時刻」慶生驚喜 SOP[cite: 6]

  • 當月壽星：贈送精緻小蛋糕一份（金額以 300 元內為原則），由領隊於旅遊途中合適地點購買；若沿途無適合蛋糕店，可調整為在地伴手禮，並同樣安排全車齊唱生日快樂歌分享。[cite: 6]
  • 多位壽星（4 人以上）：由當團 OP 事先向專門店家訂購大蛋糕，慶生需安排溫馨慶祝環節並錄影，提供線控主管卡卡與公司行銷使用。[cite: 6]

7. 氣候因素與雨天備案執行標準[cite: 6]

  • 出團判定標準：團體是否取消，一律以地方政府發布之「停止上班上課」公告為準。若出發地與旅遊地皆未發布停班停課，該團一律正常出團。[cite: 6]
  • 雨天備案執行：正常出團若遇現場降雨，領隊務必與線控卡卡共同討論調整行程，轉為執行雨天備案。[cite: 6]
  • 停班停課應變流程：即使地方政府宣布停班停課，領隊切勿自行向旅客發布取消訊息；請立即將線控卡卡加入聯絡社群（LINE 群組），由卡卡親自發布官方取消公告。[cite: 6]

二、領隊出團專業規範[cite: 6]

  1. 制服穿著標準：上身穿著公司品牌 POLO 衫或工裝背心（著背心拉鍊請拉齊至胸口），穿著黑色或深色合身牛仔褲，嚴禁穿著運動褲、休閒棉褲或拖鞋。（備註：若當天有玩水活動，當天可彈性穿著短褲；如果公司 POLO 衫或工裝背心有任何損壞破舊請主動更換）。[cite: 6]
  2. 禁菸紀律：出團期間嚴禁在客人面前抽菸。抽菸習慣屬個人行為，請於休息空檔尋找隱密處，嚴禁剛下團就在客人下車處點菸，違者直接停團處分。[cite: 6]
  3. 敬酒應對紀律：出團期間客人主動邀酒，請直接以「公司規定上班中不可飲酒」回絕；若客人熱情勸酒，請以茶代酒回敬。上班期間若有飲酒行為直接停團處分。[cite: 6]
  4. 品牌代表身分：出團期間不論是簽約領隊或外調領隊皆代表何時旅遊，客人詢問時一律以「何時旅遊簽約領隊」答覆。[cite: 6]
  5. 主動拍照留念：旅遊景點我們可能來過很多次，但對很多客人來說是珍貴的第一次。主動幫客人留下美好照片，大幅提升整趟旅遊溫度，對領隊回團製作影片亦有莫大助益。[cite: 6]
  6. 長輩關心與同理心：團體多有年紀較大的長輩，請主動關心攙扶上下階梯，不厭其煩叮嚀集合時間與洗手間方位，當成自己家人細心照護。[cite: 6]

三、接隊作業服務（SOP 與標準話術）[cite: 6]

1. 司機聯繫與提早抵達[cite: 6]

  • 集合時間前 1 小時主動致電司機大哥，確保準時抵達報到點。[cite: 6]
  • 領隊請於集合時間前 10 分鐘抵達現場，定位擺放好車條，拍攝遊覽車車頭與車牌照片提供至客人群組。[cite: 6]
  • 上車基於禮貌可先詢問司機：「大哥早安，今天氣溫較高，方便借冰箱放濕紙巾嗎？」（若冬天則不需要放）。[cite: 6]

2. 精準點名與未到通報[cite: 6]

  • 點名時務必清楚對應每位團員，嚴禁一人前來表示同伴都到就全數勾選。[cite: 6]
  • 集合時間已到若有團員未到，主動致電聯繫確認路況與抵達時間；若未接聽，立即聯繫該位客人的業務窗口雙向聯繫。集合逾時現場最長等候 10 分鐘，通聯記錄務必截圖保存以避免爭議。[cite: 6]
  • 發車前再次點名確認人數。領隊請親自走入走道由前往後逐座確認，避免夾帶未報名孩童或遺漏人數。[cite: 6]

3. 沿途多站接隊動線管理[cite: 6]

  • 開車後立即於群組發送下一站預計抵達時間（警語備註：實際抵達時間以路況為主）。[cite: 6]
  • 若有多站接隊，每一站開車後親自送礦泉水到客人座位旁，簡短問候致意，說明車上豐富的互動等最後一站接齊後正式展開，並提醒行車期間繫妥安全帶。[cite: 6]

4. 客訴案例調整：上車地點不符之現場應對[cite: 6]

當發現客人實際上車地點與報名資料不同時，避免在車上公開宣達，以免影響其他客人觀感與團體氛圍。領隊請於走道旁半蹲私下溝通：[cite: 6]

「大哥／大姐早安，這邊跟您核對一下資料，發現您原先登記的上車點在上一站，請問之前有先跟我們業務專員告知變更嗎？有跟業務說過的話就完全沒問題，我等等幫您在系統上標註好；如果是今天臨時改來這裡，因為車輛調度與保險名冊需要同步，下次出發前請記得提前跟業務說一聲，這樣我們才能為您做最好的準備喔！」[cite: 6]

若客人已通知業務，領隊立即私訊回報線控；若客人未事先通知，以私下柔和提醒化解，維持全車和諧。[cite: 6]

四、車上作業服務（互動話術與設備宣導）[cite: 6]

1. 麥克風音量測試[cite: 6]

2. 行車安全逃生設備宣導[cite: 6]

「出門放鬆玩，安全最優先。在此向大家報告我們這台車的安全防護設備：全車共有 4 個安全門、3 個車窗擊破器、2 個滅火器，以及 1 個車頂逃生門。擊破器位於兩側車窗旁，若遇緊急狀況，取下後敲擊車窗四個角落即可推開逃生。大家坐好後，也請隨手幫我把安全帶繫上，讓我們一路平平安安。」[cite: 6]

3. 領隊自我介紹與長官致詞安排[cite: 6]

  • 自我介紹重點：領隊需站在樓上走道前方與客人眼神交流，明確告知自己的稱呼（如：有問題隨時跟卡卡說），讓團員快速記住名字，建立信任感。[cite: 6]
  • 長官致詞安排：若為企業包團或特別專案團，領隊於自我介紹結束後，依清晨事先與主辦窗口確認好的名單，主動遞麥克風邀請主辦長官向全車致詞勉勵。[cite: 6]

4. 車隊介紹、空調調整與車室清潔宣導[cite: 6]

「今天為我們掌舵的是最專業沉穩的司機大哥，大家給司機大哥一個熱情掌聲！我們使用的是五年內全新的歐規豪華大巴，每台車都是正規公司車，車況穩定、保養嚴謹。車上每個座位都有專屬的空調出風口，冷氣如果覺得太強，請不要將風口全部關閉，可以將風口轉向吹向窗戶玻璃，這樣既能保持車內空氣流通，也不會直接吹到頭部。每個座位前方都有為大家準備清潔袋，抵達飯店前與回程時我會為大家集中收垃圾，隨時保持我們乾淨舒爽的車室空間。」[cite: 6]

5. 礦泉水供應與傳統倒茶服務承諾[cite: 6]

「車上的礦泉水我們準備得非常充足，是無限量為大家供應的，喝完了隨時跟我拿。另外，何時旅遊雖然是充滿朝氣的新品牌，但我們產品團隊的主管是遊覽車基層出身，非常珍惜早期遊覽車那份充滿人情味的倒茶文化。在旅途行車平穩的時段，卡卡會帶著剛泡好的熱茶，走到大家的座位旁為大家斟上一杯暖茶，讓大家在車上品茗、看風景，享受最道地的款待溫度。」[cite: 6]

6. 下層行李托運承諾[cite: 6]

「大家出門就是來放鬆的，下層行李廂的大件行李，抵達飯店時以及回程下車時，我們都會在車下一一為大家卸下來排好。大家在車上只要牽好身邊的家人、收好隨身貴重物品，慢慢走下車就好，剩下所有粗重的體力活交給卡卡來服務，讓大家出門玩得優雅又輕鬆！」[cite: 6]

  • 散客系列團：為維護全車舒適安靜的乘車品質與休息空間，行車期間僅安排影片播映或輕音樂，恕不開放卡拉 OK 點唱服務。[cite: 6]

五、品牌核心故事與文化傳遞（車上深度分享）[cite: 6]

1. 創立初心與深度客製行程開發[cite: 6]

「常常有朋友問我，何時旅遊是一家什麼樣的旅行社？我們的故事是在 2019 年開始的，當時正值觀光業最艱難的時刻，我們主管卡卡帶著團隊開發國內的深度客製行程，以細膩的照顧和扎實的好口碑一步步站穩腳步。我們總公司在苗栗，核心團隊都是在台北大型旅行社歷練十多年的專業好手。我們從苗栗出發，陸續在後龍、竹南、桃園、台北開立了五家分店，接下來更會擴展到新竹與彰化。」[cite: 6]

2. 供應鏈實力與透明定價哲學[cite: 6]

「現在何時旅遊每個月出團高達 1500 到 2000 人次，每個月有將近 70 團大客車在全台灣各地奔馳。正是因為有這麼龐大的出團量，我們能跟全台灣優質飯店、車隊爭取到非常優秀的採購條件。我們堅持透明合理的利潤，不趁熱度胡亂漲價，用實在的價格、高品質的車況與無微不至的服務回饋給大家。」[cite: 6]

3. 榮獲旅遊界奧斯卡「國際金旅獎」殊榮[cite: 6]

「2024 年 0403 地震後太魯閣休園近一年，飯店總監聯繫卡卡後，卡卡親自走了一趟花蓮，被大自然驚人的修復力與土地的強韌深深打動，回來後立刻策劃帶大家重返花蓮的精緻路線。這套行程榮獲觀光署指導、有『旅遊業奧斯卡』之稱的【國際金旅獎】！這個獎項嚴格評選行程內容、定價公道性與旅客滿意度，這份肯定讓我們更堅定要為大家端出真正有靈魂的在地行程。」[cite: 6]

六、休息站操作與景點上下車貼心服務[cite: 6]

  • 停靠節奏：平均 1 至 1.5 小時停靠一次。除回程未包晚餐需留時間讓客人買食物外，其餘操作皆為上完洗手間即發車。[cite: 6]
  • 下車前安全廣播：[cite: 6]
    「各位大哥大姐，我們抵達休息站囉！下車前請記好我們遊覽車的車號與車身顏色；如果忘記也沒關係，卡卡會穿著制服站在車頭前，看到我在哪裡，車子就在哪裡！遊覽車階梯在下雨天邊緣金屬較滑，下車請踩穩扶手；走過車頭時請特別留意兩側的大型後照鏡高度，小心不要撞到頭。遊覽車完全停穩、車門打開後，大家再站起來下車喔！」[cite: 6]
  • 景點「5:5 導覽法則」：一小時的時間，前半小時帶著客人走訪核心拍照點，後半小時保留給客人自由逛街。[cite: 6]
  • 覆誦式宣達集合時間：[cite: 6]
    「我們這站預計停留到下午三點半，三點半遊覽車發車。請問各位家人，我們等等幾點車上集合？（引導全車齊聲回應：三點半！）太棒了，大家默契非常好！」[cite: 6]
